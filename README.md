# Modulo-13-ebac

# Análise Exploratória de Dados - Módulo 13 (EBAC)

Este repositório contém a resolução dos exercícios do módulo 13 do curso da EBAC.

## 🛠️ Tecnologias Utilizadas
* Python
* Pandas
* Seaborn / Matplotlib
* Plotly

## 📊 Principais Tópicos Abordados
* Análise de medidas de tendência central (Média e Mediana)
* Identificação de dispersão e outliers com Desvio Padrão e Boxplot
* Gráficos interativos (Treemap) para análise de desconto por Categoria e Marca
